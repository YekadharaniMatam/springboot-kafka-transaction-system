# Spring Boot Kafka Transaction System
# JPMorgan Chase Software Engineering Virtual Experience

## Overview

This project was completed as part of the JPMorgan Chase & Co. Software Engineering Virtual Experience Program on Forage.

The application simulates a backend financial transaction processing system using Spring Boot, Apache Kafka, REST APIs, and SQL database integration.

## Technologies Used

* Java
* Spring Boot
* Spring Framework
* Apache Kafka
* REST APIs
* Spring Data JPA
* H2 SQL Database
* Maven

## Features

* Kafka-based transaction message processing
* Transaction validation and persistence
* User balance updates
* REST endpoint for balance retrieval
* Incentive API integration using RestTemplate
* Database entity relationships using JPA
* Automated testing with Maven and Embedded Kafka

## System Workflow

1. Kafka producer sends transaction messages
2. Kafka listener consumes transaction data
3. Transactions are validated and processed
4. User balances are updated in the database
5. Transaction records are stored
6. REST API exposes balance information

## What I Learned

* Event-driven architecture using Kafka
* Backend development with Spring Boot
* REST API development
* Database integration using JPA
* Debugging and testing distributed systems
* Microservice communication patterns
